PyAerial

PyAerial is the ADS-B/Mode-S tracker I built for AERPAW at NC State (successor to airstrik.py). It decodes 1090 MHz transponder traffic, stores flight history, and fires programmable alerts when aircraft enter user-defined geofences. The stack is modular so extra data sources (OpenSky, dump1090, RTL-SDR) and notification backends can be swapped in.

Features

  • •15% faster collision detection
  • •92% fewer false positives
  • •Flight history in MongoDB
  • •Dockerized deployment
  • •Kafka notification integration
  • •Common geofence file formats

ML-Ticker

ML-Ticker is a Python command-line tool I built during my Merrill internship to query FactSet FQL snapshot and historical data. A sandboxed Python formula engine computes post-query custom metrics, an automatic dependency DAG plus Pydantic validation catch bad configs, and output goes to colorized terminal tables or styled Excel sheets.

  • •Sandboxed Python formula engine for post-query custom metrics
