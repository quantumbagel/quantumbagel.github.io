Presence without scraping

Amazon Music Discord RPC is a browser extension plus a Rust native-messaging host. The extension reads the Media Session API and first-party Amazon metadata. It does not scrape the DOM. The host speaks Chromium and Firefox native messaging on one side and Discord IPC on the other.

Private repository. The interesting part is the process boundary, not a screenshot of a Discord popup.

The host is the product

JS in a tab cannot talk Discord IPC cleanly. Native messaging is the boring, correct pipe. The Rust host coalesces updates, rate-limits them (5 / 20s), and reconnects. If you skip those, you either get rate-limited by Discord or you flicker the presence on every progress tick.

I wanted a small native binary I could reason about, not another Electron tray app.
